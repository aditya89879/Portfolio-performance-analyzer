# Portfolio Performance Analyzer
Portfolio Performance Analyzer (2025)

Developed a Python-based Portfolio Performance Analyzer to understand stock market trends and basic investment analysis. The project tracks the performance of multiple stocks and compares their returns over a selected period of time using financial data.

Used Python libraries along with stock market data to calculate portfolio returns, analyze profit/loss trends, and compare the performance of different companies. The project also helped in understanding concepts such as diversification, risk comparison, and market movement. Through this project, I improved my understanding of financial analysis, data handling, and the practical use of Python in finance-related applications.
